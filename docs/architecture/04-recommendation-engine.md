# Recommendation Engine

Owner subsystem:

- Recommendation Engine

# Purpose

The Recommendation Engine should retrieve and rank places, experiences, and travel options that are relevant to a user or planning context.

# Current Status

Conceptual only. Not yet a dedicated engine.

Hero Card is not a recommendation engine today. It operates primarily on a user’s own saved places.

# Current Responsibilities

- no standalone implementation yet

# Future Direction

- retrieve relevant places beyond current saves
- support discovery ranking
- support planner completion and gap filling
- rank by user preference, opportunity, and context

# Key Questions

- should recommendations operate on saved places, global places, or both?
- how will retrieval differ for Discovery versus Planner?
- how much ranking should be heuristic versus AI-assisted?
