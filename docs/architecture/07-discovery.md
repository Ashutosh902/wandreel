# Discovery

Owner subsystem:

- Recommendation Engine
- Opportunity Engine

# Purpose

Discovery should help users find relevant places, themes, and opportunities beyond a simple list of what they already saved.

# Current Status

Early and mostly UI-driven.

Today, Discovery is still heavily rooted in:

- bucketlist summaries
- category entry points
- recently added places
- early hero-driven navigation into existing saved content

# Current Responsibilities

- entry point into user-saved place exploration
- category browsing
- home-level interpretation through Hero Card

# Future Direction

- recommendation-driven discovery
- social discovery
- context-aware discovery
- dynamic opportunity-driven discovery surfaces

# Key Questions

- when does Discovery stop being a saved-place browser and become a recommendation surface?
- how should Discovery differ from Hero Card?
- how should social and planner signals feed back into Discovery?
