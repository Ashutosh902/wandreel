# User Journeys

# 1. Save Inspiration

User sees a reel or travel link and wants to save it.

Desired result:

- content becomes structured
- place is categorized
- save feels fast and trustworthy

# 2. Revisit Saved Places

User has many saved places and wants to understand what is worth acting on next.

Desired result:

- home or discovery surfaces an actionable insight
- user can jump directly into a relevant view

# 3. Plan a Trip

User has enough saved places to move from collecting to planning.

Desired result:

- planner can turn saved places into routes or itineraries

# 4. Share and Discover Socially

User wants to share good places or benefit from friends/community.

Desired result:

- Connect becomes a source of trust-weighted discovery and future collaboration
